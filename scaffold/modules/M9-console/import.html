设计数据导入

读路段：本页 → M9 /gw/ → M6 统一数据出口 → M3 rpdao。 上传导入：本页 → M9 /v1/design/import → M2 接入服务 → M3 rpdao。 两条路都不接触数据库。
为什么导入不经 /gw：/gw 的契约是 「有边界的只读转发，不是通用代理」（只许 GET），而导入是写。 M6 那边倒有 POST /v1/actions/{action_name}，但那是受治理动作—— 要权限校验、副作用、写回、审计留痕，且默认人工确认后才执行；数据接入不属于那一类。 所以导入直连 M2。M9 的硬线是「不得直连数据库」，这一条仍然是 HTTP。
