# contracts/ —— 指针

本目录**不再持有契约副本**。正本在：

```text
scaffold/contracts/delivery/artifact_manifest.v0.1.schema.json
```

## 为什么只留一份

宪法「接入约束」要求契约文件提交到 `scaffold/contracts/`。
speckit 的设计稿习惯把契约放在 spec 目录下。

两个位置各放一份会**漂移**，而漂移的方向永远是**设计稿过期** ——
改的人改正本，忘改副本，后来的人读到的是过期的约束。
一份正本加一个指针，没有这个问题。

## 契约内容

**仿真产物清单 v0.1** —— 交付目录 `artifacts/sim/` 的清单。

M9 的 `GET /artifacts/{name}` **只接受清单里登记的名字**。
目录里存在但清单里没有的文件，取不到。

★ 这把「新增资产必须登记」从一句纪律变成**结构上做不到** ——
与宪法原则 II 的口径一致（"结构上做不到"优于"我们约定不这么做"）。
